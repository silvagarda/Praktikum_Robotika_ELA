# ROS 2 TurtleBot3 Docker Setup

## Cara Menjalankan
Jalankan perintah berikut secara berurutan di terminal:

1. Clone repositori ini:
   git clone <URL_REPOSITORI_KAMU>

2. Masuk ke folder docker:
   cd robotics-turtlebot3/docker

3. Build image:
   docker compose build

4. Jalankan node talker dan listener:
   docker compose up
